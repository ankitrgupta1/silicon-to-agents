# Prerequisites

The background the rest of the stack assumes. Not a stack layer: this is where the Fundamentals path begins.

## Topics

| Topic | What it covers | Status |
|---|---|---|
| Linear algebra | Vectors, matrix multiply, SVD and low-rank ideas (used by LoRA) | planned |
| Calculus & backprop | Chain rule, gradients, building autograd from scratch | planned |
| Probability & information | Softmax, cross-entropy, KL divergence, perplexity | planned |
| Optimization | SGD, momentum, Adam/AdamW, learning-rate schedules | planned |
| Python & PyTorch | Tensors, autograd, `nn.Module`, `torch.compile`, profiling | planned |
| ML basics | MLPs, overfitting, regularization, train/val/test splits | planned |

## Start here

- 3Blue1Brown, *Essence of Linear Algebra* and *Neural Networks* video series (F)
- Deisenroth, Faisal & Ong, *Mathematics for Machine Learning* (free online) (F)
- Andrej Karpathy, *Neural Networks: Zero to Hero*, starting with micrograd (F, B, P)
